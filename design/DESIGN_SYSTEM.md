# PillNote 웹 디자인 기준

웹 기본 글꼴은 로컬 Pretendard Variable이다. 앱 캡처는 원본 글꼴을 유지한다. 모든 웹 글자 크기·굵기·줄 간격은 `src/design-system.css`에서 역할별로 정의한다. 화면이 작을 때는 배치를 바꾸고 본문과 보조 문구를 더 작게 축소하지 않는다.

| 역할 | 크기 | 굵기 | 줄 간격 | 사용처 |
| --- | --- | --- | --- | --- |
| 첫 화면 문구 | 반응형32~64px | 700 | 1.25 | 첫 소개 문구 |
| 섹션 제목 | 32~48px, 모바일28px | 700 | 1.25 | 기능 소개·이용 안내 |
| 구성요소 제목 | 24px | 650 | 1.25 | 상세 패널 제목 |
| 상단·모바일 메뉴 | 16px | 600 | 1.5 | 앱 소개·제품 요약·다운로드·언어 선택 |
| FAQ·본문 버튼 제목 | 18px, 모바일16px | 600 | 1.5 | FAQ 질문·본문 출시 버튼 |
| 본문·설명 | 16px | 400 | 1.6 | 기능 설명·FAQ 답변 |
| 라벨 | 16px | 600 | 1.5 | 기능 이름·상태 |
| 보조 문구 | 14px | 400 | 1.5 | 기능 요약·출처·개발자 정보 |
| 로고 | 24px, 모바일22px | 700 | 1.25 | 동일한 PillNote 로고 |

첫 화면의 큰 PillNote 워드마크는 별도 display 역할로 관리한다. 그 외 역할이 같은 글자는 배치 장소에 따라 다른 크기를 쓰지 않는다. 웹 텍스트 최소 크기는14px다. 실제 앱 캡처와 휴대폰 시스템 화면의 글자는390×844논리 화면의 원래 비율을 따른다.

상단 바는 데스크톱80px, 모바일64px다. 컨트롤은 데스크톱48px, 모바일44px 이상의 높이를 확보한다. 상단 화살표는20px, 모바일 메뉴 아이콘은24px다. 모바일의 부가 메뉴는16px글자와44px이상의 영역으로 별도 메뉴에 표시한다. 버튼 모서리는12px, 공통 간격은8/16/24px다.

언어 선택 KO/EN도 같은 메뉴 글자와 컨트롤 높이를 사용한다. 하나의 배경 안에서 흰 선택 표시가220ms동안 이동하며, 선택 상태는 초록 글자와 aria-pressed로 표시한다. 변경되는 텍스트만 위에서 아래로 지연을 두고 닦아내며 교체한다. 읽던 문구의 화면 내 위치와 FAQ 펼침 상태를 유지한다. 모바일에서는 메뉴 안에 배치한다. 다운로드 버튼은 데스크톱148px, 모바일128px이상의 너비를 확보해 한국어·영어 전환에도 헤더가 흔들리지 않는다. 소개와 이용 안내의 영어 문구도 동일한 역할과 크기를 따른다.

첫 화면의 출시 예정 라벨과 안내 팝업은 표시하지 않는다. 다운로드와 GitHub 릴리즈 링크는 실제 릴리즈 목록으로 바로 연결한다. 페이지 스크롤바는 숨기지만 스크롤은 유지한다. 목차 이동은 부드러운 스크롤을 사용하며, 동작 감소 설정에서는 전환과 스크롤 애니메이션을 생략한다.

본문·보조 문구에는 동일한 보조 색상을 사용한다. 섹션 라벨만 브랜드 초록을 사용한다. 캡처된 앱의 색상과 타이포그래피는 웹의 기준으로 바꾸지 않는다.

소개 문구는 기능과 결과를 짧게 전달한다. “추가해 볼게요”, “눌러봐요”, “이제 …” 같은 진행자 말투나 단계별 조작 자막은 사용하지 않는다. 같은 기능 안에서는 설명을 고정하고, 실제 조작 과정은 스크롤에 연결된 앱 화면으로 전달한다.

앱 내부 전환은 Flutter 엔진의 iOS 렌더 프레임을 사용한다. 웹에서 두 화면을 크로스페이드하거나 변형하지 않고, 스크롤 진행도에 따라 중간 프레임을 선형 선택한다. 곡선과 그림자, 버튼의 잉크 효과는 이미 Flutter가 적용했다. 별도의 원형 터치 표시를 덧붙이지 않는다. 웹에서 만든 잠금 화면 알림 예시는 앱 내부 렌더와 구분한다.
