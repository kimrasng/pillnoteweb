# PillNote Web

PillNote Flutter 앱의 실제 기능을 소개하는 출시 예정 웹사이트입니다. React, TypeScript, Vite를 사용하며, 복약 기록 → 약 관리 → 알림 → 보호자 연결 → 의약품·약국 정보 순서로 이어집니다.

## 실행

```bash
cd /Users/kimrasng/dev/pillnoteweb
npm install
npm run dev
```

터미널에 표시되는 주소(기본 `http://127.0.0.1:5173`)를 브라우저에서 여세요.

```bash
npm run build       # TypeScript 검사와 배포용 정적 파일 생성
npm run preview     # dist 빌드 결과 확인
npm run typecheck   # TypeScript 검사
npm run format      # 코드 정리
```

`dist/`는 추후 정적 웹 호스팅에 올릴 수 있습니다. 이 작업에서는 외부 배포를 하지 않았습니다.

## 구성과 동작

- 반응형 소개 페이지, 고정 헤더, 구간 내비게이션, 읽기 진행 표시, 자연스러운 스크롤과 등장 효과
- 데스크톱에서는 소개 내용에 맞춰 앱 예시 화면이 바뀌고, 모바일에서는 탭으로 직접 선택
- 예시 날짜별 복약 체크·취소, 진행률, 모든 날짜 기록에 따른 수량 차감, 알림 스위치, 초기화
- 보호자 알림 예시, 의약품 검색과 약국 지도 소개, 로그인 없이 시작하는 기기 저장 안내
- 자주 묻는 질문, 출시 안내 모달, `mailto:dohyun.kim@pillnote.app` 문의 링크
- 키보드 내비게이션, 기본 HTML dialog의 포커스 관리·Escape 닫기, 동작 줄이기 설정 대응

화면의 약 이름과 기록은 설명을 위한 가상 예시입니다. 예시 데이터는 컴포넌트 메모리에만 유지되며 새로고침하면 초기화됩니다. 실제 앱, 서버, 약 검색 API, 위치 서비스와 연결하지 않습니다. 출시 안내는 다운로드 링크나 출시일을 임의로 제공하지 않습니다.

## 수정할 곳

- `src/App.tsx`: 문구, FAQ, 가상 약 데이터, 인터랙션, 출시 안내
- `src/styles.css`: 파란색 중심의 디자인, 반응형 레이아웃, 모션
- `index.html`: 페이지 제목, 설명, Open Graph 메타데이터
- `public/images/`: 웹에 사용되는 최적화 이미지
- `design/`: 원본 이미지와 제작 기록

로고는 기존 PillNote 앱 아이콘을 사용했습니다. 본문 색상은 앱의 파란색(`#2563EB`)을 기반으로 하며 로고의 청록색을 보조색으로 사용했습니다. Google Fonts의 Manrope와 Noto Sans KR을 불러오고, 연결할 수 없으면 시스템 글꼴로 표시합니다. 첫 화면의 아침 이미지는 기본 내장 이미지 생성 도구로 제작했으며, 생성 프롬프트는 로컬 문서로만 보관합니다.

서비스 설명은 형제 폴더 `../pillnote`의 README와 홈·약 관리·약국·알림 구현을 분석해 작성했습니다. Toss 사이트는 여백, 큰 타이포그래피, 둥근 장면과 이어지는 서비스 소개 방식의 참고로 사용했습니다.
