# PillNote Web

PillNote Flutter 앱의 사용 과정을 직접 체험하는 React 웹. 출시 전 소개 페이지이며 배포하지 않았습니다.

## 실행

Node.js 24 이상 권장.

```sh
npm install
npm run dev
```

기본 주소: http://127.0.0.1:5173/

```sh
npm test
npm run build
npm run preview
```

`dist/`가 정적 웹 빌드 결과입니다.

## 경험 구성

하나의 큰 앱 화면을 고정하고 스크롤에 따라 오늘의 복약 → 약 등록 → 복용 기록 → 약 상자 → 시간 알림 → 보호자 연결 → 주변 약국으로 이동합니다. 각 단계의 자동 시연을 앱 내부 조작으로 중단하고 직접 사용할 수 있습니다. 다음 단계까지 바깥 화면을 스크롤하면 시연이 이어집니다.

약 검색과 직접 입력, 복용량·단위·시간·수량 설정, 복용 체크와 취소, 날짜별 기록, 수량 연동, 약 수정·보관·복원, 약 묶음, 알림 스위치, 보호자 초대·수락, 지도 이동·확대·약국 선택이 동작합니다. 모든 화면이 같은 메모리 데이터를 사용합니다.

## 데이터와 출시 상태

- 샘플 약과 약국을 사용합니다. 실제 의약품 API나 약국 검색 API와 연결하지 않았습니다.
- 입력과 기록은 현재 페이지의 메모리에만 유지되며 새로고침하면 초기화됩니다.
- 이메일, 푸시와 기기 알림은 발송하지 않습니다. 계정 로그인 화면도 실제 인증이 아닙니다.
- 지도는 화면을 열 때 [OpenStreetMap](https://www.openstreetmap.org/copyright)의 온라인 타일을 불러옵니다. 사용자의 위치는 요청하지 않습니다. 서울시청 기준의 공개 위치와 예시 약국을 표시합니다.
- 실제 앱의 기본 약 관리와 알림은 로그인 없이 사용하며, 동기화와 보호자 연결은 이메일 로그인, 초대 수락과 알림 설정이 필요합니다.
- 보호자 알림은 기록 확인 요청입니다. 실제 미복용을 확정하지 않습니다.
- 다운로드 링크는 출시 이후 제공할 수 있도록 현재는 출시 예정 안내를 표시합니다.

## 주요 파일

- `src/App.tsx`: 고정된 스크롤 장면, 시연 제어, 웹 메뉴와 출시 안내
- `src/DemoApp.tsx`: 실제 조작 가능한 앱 미리보기
- `src/demo.ts`: 공통 데이터, 복용·수량 기록, 약 묶음
- `src/PharmacyMap.tsx`: Leaflet 지도와 예시 약국
- `src/styles.css`: 웹과 앱 화면 스타일, 반응형, 동작 감소 설정
- `test/demo.test.mjs`: 수량과 기록 데이터 검증
- `design/v1/`: 이전 소개형 시안 보관
- `design/QA.md`: 이번 개편 검증 내역
