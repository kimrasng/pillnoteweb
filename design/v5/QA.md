# PillNote Web — 스크롤 연동 소개 QA

확인일: 2026-10-12. 로컬에서 검증했으며 배포하지 않았습니다.

## 변경

첫 화면에 앱 대신 “복약 관리도 간편하게. PillNote” 전체 화면 문구를 표시합니다. 스크롤 좌표에 따라 컨테이너가 가운데로 줄어들고, 문구가 사라지며 실제 앱 캡처가 나타납니다. 앱의 터치 표시, 화면 전환과 장면 경계도 같은 스크롤 좌표에서 계산합니다.

앱 재생용 타이머와 CSS 애니메이션을 제거했습니다. 휴대폰 외곽은 장면 사이에 유지하며, 이전 캡처와 다음 캡처를 합성해 연결합니다. 사용자가 앱을 클릭하거나 입력할 수 없습니다.

## 반응형

1536×960, 1280×800, 768×1024, 390×844, 320×568, 844×390에서 확인했습니다. 가로 넘침이 없으며 휴대폰 화면 비율은 390/844 ≈0.462085를 유지합니다. 이미지가 늘어나거나 잘리지 않습니다.

390×844에서 도입부 앱 미표시, 앱 등장, 캡처 설명과 하단 문구 사이의 간격을 확인했습니다. 지도 장면도 겹침 없이 표시됩니다. 모바일 설명 행 높이를 고정해 장면마다 휴대폰 위치가 튀지 않도록 했습니다.

320×568에서는 소개 이후 장면별 휴대폰을 고정하고 스크롤로 해당 시연을 진행합니다. 등록 진행도 약0.215 →0.465 →0.215에서 검색 →시간 설정 →검색 복원을 브라우저에서 확인했습니다. 휴대폰 전체가 상단64px에서 하단528px 사이에 들어옵니다.

844×390에서는 자연스러운 페이지 스크롤 분기, 도입부 카드 안의 휴대폰 배치와 화면 비율을 확인했습니다. 임시 브라우저 크기는 마지막에 기본값으로 복원했습니다.

동작 감소 설정은 소스와 순수 함수 테스트로 확인했습니다. 확대·축소와 터치 표시를 생략하고 캡처를 스크롤 단계에 맞춰 즉시 전환합니다. 보조기기로 모든 흐름을 별도로 검증하지는 않았습니다.

## 자동 검증

`npm test`: 16개 통과.

- 같은 스크롤 위치 유지와 순방향·역방향 복원
- 등록 단계, 큰 스크롤 이동과 프레임 경계
- 캡처 합성 중 배경 노출 방지와 중복 이미지 처리
- 터치 표시의 구간 제한과 동작 감소 설정
- 장면 사이 연결과 역방향 전환
- 도입부, 장면 경계, 마지막 구간 제한
- 목차 탐색 좌표, 화면 크기 변화와 좌표 계산

`npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.

## 실제 앱 캡처

원본 Flutter 앱의 페이지·테마·Pretendard 글꼴·아이콘으로 만든 14개 PNG를 사용합니다. 모두780×1688, 논리390×844입니다. 실제 복용 처리로 체크와 수량14정→13정 변화를 캡처했습니다. 캡처 테스트는 통과했으며 원본 앱 소스는 변경하지 않았습니다.

캡처 코드·출처·이미지 크기·SHA-256은 `design/capture/`에 있습니다. 보호자 캡처는 실제 로그인 전 안내이고 지도는 서울시청 중심의 실제 OpenStreetMap 화면입니다. 웹은 실제 계정, 위치, 검색 API, 메일, 푸시나 기기 알림에 연결하지 않습니다.
