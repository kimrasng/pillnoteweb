# PillNote Web — 앱 내부 동작 QA

2026-10-12. 로컬 미리보기 반영, 배포 없음. 이전 기록은 `design/v5/QA.md`에 보존했다.

## 구현

한 기기 안에서 내 약 상자 → 약 추가 → 검색어 입력 → 검색 결과 선택 → 복용 시간 설정 → 실제 시간 선택 창 → 등록 → 홈 → 복용 체크 → 약 상세로 이어진다. 약 상자는 체크한 상태의 13정을 유지한다. 알림 카드는 잠금 배경과 시계를 유지한 채 도착하며, 열면 앱이 나타난다. 보호자 초대/수락/연결과 보호자 휴대폰 알림을 이어서 소개한다. 서울역 지도에서 실제 목록이 315 논리 px 이동하고, 센츄럴팜약국 상세 시트는 아래에서 올라온다.

기기 몸체·베젤·측면 버튼·Dynamic Island는 Hoverify의 기존 iPhone 18 Pro Silver WebP다. 파일과 개구부의 치수/사용 라이선스는 `design/device/README.md`에 기록했다. 앱 캡처의 390/844 비율은 유지한다. 실제 Flutter UI 캡처 24개(780×1688)는 manifest SHA-256와 치수를 갱신했다. 추가 캡처 테스트가 통과했고 원본 Flutter 저장소는 clean이다.

휠 입력은 앱에서 56%, 도입부에서 82%로 반영하며 105ms 시정수로 감속한다. 휠 방향을 바꾸면 이전 목표를 취소한다. 포인터·키보드 입력과 resize는 감속을 중단한다. 터치/키보드/동작 감소 설정은 기본 스크롤을 사용한다. 앱 재생은 시간을 참조하지 않으며 스크롤 좌표가 모든 포즈를 결정한다.
