Product & development

A working app, with public releases.

PillNote brings dose schedules and records, medication search and management, local reminders, email sign-in and sync, caregiver connections and check-in alerts, and nearby pharmacy search into one Flutter app. Users can start without signing in; caregiver connections require sign-in and an accepted invitation.

The current public installation is an Android APK distributed through GitHub Releases. Our public source code, release history, and development history are available below.

How we use Claude

Claude is used as a tool in PillNote's development process. The current app does not directly use the Claude API for in-app features.

PillNote helps users manage medication routines. It does not provide diagnosis or treatment advice.
